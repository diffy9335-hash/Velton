# VELTON v0.9 — массовый офлайн-импорт реальных составов, футбол без API

**Версия:** 15 ноября 2026. Telegram-бот + Mini App (FastAPI, SQLite, HTML/CSS/JS).

**Футбольный API, ключ провайдера и статический IP НЕ НУЖНЫ.** Сервер не обращается к сторонним футбольным сервисам. Реальные названия клубов и имена игроков хранятся в локальных JSON-пакетах `world_data/packs/`; результаты матчей, календарь, таблицы, трансферы, призовые, бюджеты, зарплаты, рейтинги и развитие карьеры считает исключительно игровой движок VELTON. Для входа через Telegram и открытия Mini App интернет/HTTPS всё равно нужны.

## Новое в v0.9 — как добавить тысячи настоящих футболистов за один импорт

**Фактически внутри ZIP по-прежнему находятся 1 453 клуба и 1 070 имён, из которых 1 009 доступны новым сохранениям.** У 1 358 клубов нет названных футболистов. Никакого заявления о «всех готовых составах» здесь нет.

Добавлены два пакетных офлайн-конвертера и аудит по всем 1 453 клубам. Первый импортирует датированные CSV 2026-07 из публичного проекта `dcaribou/transfermarkt-datasets` с однократным скачиванием без ключа API, второй — опциональный локальный CSV FC 26 по лицензии пользователя. Применение пакета происходит при перезапуске сервера и **только к новым карьерным слотам**. Для заявок 2026/27 у 29 клубов сохраняется приоритет официально подтверждённых списков.

```bash
# Однократно скачать публичный исторический снимок и подготовить JSON с аудитом
python tools/install_real_rosters_v09.py --download
# Изучить world_data/snapshots_v09/velton_real_2026_07_bulk.audit.json
# После проверки установить в офлайн-каталог для будущих сохранений
python tools/install_real_rosters_v09.py --install
# Получить точный отчёт о 80 лигах после установки
python tools/audit_squads_v09.py
```

После установки снимка **запуски матча, лиги и трансферы остаются полностью офлайн относительно футбольных провайдеров**. Интернет нужен только для разового скачивания с компьютера оператора. Если он недоступен — файлы CSV можно заранее скопировать локально. Скрипты защищают от несуществующих клубов и конфликтов имён; близкие по написанию команды не связываются автоматически.

[Технические условия, недостатки и инструкция по сопоставлению клубов](docs/FULL_ROSTERS_v09_RU.md) · `docs/coverage_v09.csv` (встроенное состояние до массовой загрузки).

## Что уже действительно доступно

- **35 стран/футбольных ассоциаций, 80 лиг, 1 504 плановых места для клубов** — структура чемпионатов и правила переходов (часть правил пока упрощена).
- **1 453 клубные записи и 1 070 настоящих имён футболистов** — офлайн-каталог в пяти пакетах плюс сверенные заявки 2026/27 `world_data/packs/`. Все **80 лиг** теперь имеют команды, **59** достигли планового количества, **21 лига** заполнена частично, ни одна не пустует. Подтверждённые полные заявки имеются у 29 клубов, а остальные составы частичные; остальные клубы не получают вымышленные полные составы. Данные исторические, из разных сезонов, актуальность на ноябрь 2026 по всему миру не гарантируется. Полный отчёт: [COVERAGE_v06_RU](docs/COVERAGE_v06_RU.md), CSV `docs/coverage_v06.csv`.
- **Пять независимых карьер:** игрок, тренер, судья, агент и владелец клуба. Один аккаунт, профиль, опыт и награды, до пяти сохранений.
- **Матчи:** сезонный календарь с ответными встречами, голы и таблицы по матчам, тактика тренера, трансферный рынок, годовая экономика и статистика. При переходе в сезон 2 таблицы сбрасываются, история предыдущего сезона остаётся, доступен уход из карьеры с удалением слота.
- **Межсезонный рынок ИИ:** между сезонами клубы, для которых в офлайн-пакете подтверждено достаточно имён футболистов, совершают самостоятельные сделки. Суммы и рейтинги — игровая модель; чужие карьеры и исходный каталог не изменяются. ИИ не торгует футболистами подконтрольного тренеру/владельцу клуба.
- **Модель сроков контрактов:** у футболистов сохраняется условный сезон окончания игрового соглашения, а новая покупка записывает контракт на три сезона. Полная система переговоров, истечения и свободных агентов пока **не реализована**.
- **Сохранения — снимки:** новые локальные реестры добавляют команды и футболистов **только в новые слоты**. В уже созданные сохранения изменения каталога не навязываются, включая существующие трансферы.

## История v0.7 — игроки из снимков сборных


- **97 новых подтверждённых имён**, которых не было в предыдущей версии: всего **761 имя** в автономном каталоге, **96 клубов** с хотя бы одним известным игроком. В пяти ведущих лигах суммарно **636 игроков в 81 клубе из 96**. Это **частичные составы, не полные заявки**.
- Пакет `world_data/packs/velton_verified_players_v07.json` содержит конкретные имена и позиции из снимка заявок сборных ЧМ-2026 (источник и **CC BY 4.0** в `THIRD_PARTY_NOTICES.md`). Из снимка добавлены только клубы пяти высших лиг, для которых соответствие названию однозначно. Игроки с конфликтующими историческими клубами пропущены, а не дублированы.
- Матчевый движок теперь правильно учитывает **GK / DF / MF / FW**: вероятность гола зависит от позиции, нападающие забивают чаще вратарей. Это статистика только **внутри игрового мира VELTON**.
- Mini App показывает позиции по-русски: «Вратарь», «Защитник», «Полузащитник», «Нападающий». Игровые бюджеты и трансферы остались прежними.
- Добавлен **конвертер локальных снимков** `tools/convert_roster_snapshot.py`: читает скачанные TSV/CSV, сопоставляет клубы с пятью ведущими лигами, пропускает неизвестные и конфликтующие записи, сохраняет отчёт. Футбольный API, сетевой доступ, ключ или IP **не требуются**.
- **31 автоматический тест пройден** (в том числе переходы, независимые слоты, отсутствие повторного импорта и проверка позиций). Docker/публичный Telegram не развёртывались.

**Честный остаток работы:** полных составов для всех 96 клубов ведущей пятёрки пока нет — подтверждено 29/96. Источники за разные даты, часть клуба может иметь одного подтверждённого игрока. План остальных 51 клубного места и 21 частично заполненная лига сохраняются.

[Аудит пяти чемпионатов и 80 лиг](docs/COVERAGE_v07_RU.md) · `docs/coverage_v07.csv` · `world_data/verified_players_audit_v07.json`.

### Следующее пополнение без онлайн-сервиса

Если у тебя есть легально скачанный актуальный TSV игроков сборных указанного формата или CSV с полями `name,club,position,club_country` (подробности в `tools/convert_roster_snapshot.py`), создавай пакет **локально**:

```bash
python tools/convert_roster_snapshot.py ./players.tsv ./new_players.json --format fifa26 --source-url https://github.com/matyuschenko/fifa-wc2026-players/blob/main/data/players.tsv
python tools/import_rosters.py ./new_players.json --install
```

Скрипт для необязательного CSV BeyondELO: `--format beyondelo` (источник: https://beyondelo.com/developers); устанавливать разрешено только данные на условиях поставщика. Скрипт **не скачивает** файлы и не подключается ни к одному внешнему сайту. После импорта перезапусти сервер, новые имена будут доступны только при создании **нового слота**. Если клуб не совпадает с каталогом или футболист уже указан в другом клубе, запись пропускается и отражается в `.audit.json`.

## Как запустить на ПК

Python 3.10+:

```bash
pip install -r requirements.txt
```

Скопируй `.env.example` в `.env`, установи в `.env` `DEMO_MODE=1` для локальной проверки и запусти:

```bash
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Открой `http://127.0.0.1:8000`. Деморежим **не предназначен для публичного сервера**.

## Запуск с Telegram

1. Получи `BOT_TOKEN` от `@BotFather`.
2. Укажи в `.env`: `BOT_TOKEN=...`, `APP_URL=https://свой-домен/`, `DEMO_MODE=0`.
3. Запусти сервер (см. команду выше; на сервере можно использовать `--host 0.0.0.0`).
4. Вторым процессом запусти `python bot.py`.
5. Нажми `/start` в боте. Сессия Telegram проверяется по криптографической подписи `initData`.

Для Docker: `docker compose up --build -d` после настройки `.env`. Для безопасности не публикуй `.env`, делай резервные копии `data/velton.sqlite3`.

## Как добавлять всех реальных клубов и игроков **без футбольного API**

Сохраняй сверенные названия и составы в обычном CSV/JSON. У каждого клуба обязательно указывать источник; рейтинг/стоимость/зарплата не импортируются из интернета, их считает VELTON.

**Вариант 1 — вручную подготовленный CSV (клубы + футболисты):**

```bash
python tools/rosters_csv_to_pack.py world_data/EXAMPLE_NEW_CLUBS.csv world_data/next_league.json
python tools/import_rosters.py world_data/next_league.json --install
```

CSV колонки: `league_id,club,player,position,age,nationality,source`. Если `player` пустой, добавится только клуб. Повторяющиеся футболисты не дублируются. Импорт в папку `world_data/packs/` начнёт применяться **после перезапуска** сервера и только для новых слотов. При проверке проекта примерный CSV содержит уже известный «Арсенал» и служит только примером формата.

**Вариант 2 — публичные статические списки клубов:** проект [openfootball/football.json](https://github.com/openfootball/football.json) распространяет свои файлы футбольных матчей под CC0. Можно **заранее** сохранить файл JSON на компьютер, извлечь из него **только названия клубов**, затем использовать их в полностью автономной игре:

```bash
python tools/openfootball_json_to_pack.py ENG_3 ./my_downloaded_fixture_snapshot.json ./league3.json --source https://github.com/openfootball/football.json
python tools/import_rosters.py ./league3.json --install
```

Настоящие результаты из такого файла в игру **не переносятся**. По совпадению имён существующий клуб пополняется футболистами, но не дублируется. Остались 21 частично заполненная лига; в них нельзя добавлять случайные названия для достижения плановой цифры. Другие уже содержат реальные названия клубов, но не все составы игроков. Никому не нужно создавать ключ API или настраивать адрес IP.

**Реальные имена не означают, что состав актуален до сегодняшнего дня.** Для публикации и коммерческого использования футбольной символики, фотографий и массовых лицензируемых датасетов отдельно проверяй права и актуальность источников; клубные логотипы и фотографии игроков в архив не включены.

## Не реализовано и честные ограничения

- Проверка остальных **51 места до плановых 1 504** и полных актуальных составов: сейчас 1453 клубные записи и 1070 имён футболистов. Сам механизм офлайн-импорта уже готов. У каждого следующего JSON-пакета нужен источник настоящих имён; выдуманные имена ради количества не используются.
- Все официальные форматы низших дивизионов, молодёжные академии, еврокубки, реалистичные контрактные переговоры, система управляемых матчей, полностью специализированные карьеры судьи/агента, создание собственного клуба с нуля, полноценные трансферные окна.
- Календарь пока разыгрывается за 12 ходов сезона: это **схематичная игровая шкала**, не 12 реальных недель и не официальные расписания.
- Серверная реализация протестирована автоматическими тестами; Docker-образ и публичная интеграция в Telegram в этой среде не запускались.

## Файлы

- `server.py` — сервер, Telegram-подписи, API карьер, итогов и слотов
- `world.py`, `engine.py` — изолированные игровые миры, чемпионаты, рынки, сезоны
- `offline_catalog.py` — валидация и загрузка проверенных статических данных

- `tools/build_v06_pack.py`, `tools/build_coverage_pack.py` и `tools/build_wc2026_players.py` — воспроизводимая генерация данных из **встроенных** проверенных списков (без сети)
- `tools/` — инструменты преобразования локальных CSV/JSON **без интернета**
- `static/` — минималистичная голубая Telegram Mini App
- `tests/` — проверки лиг, календаря, денег, изоляции миров, отчётов, миграций

Для проверки: `pip install -r requirements-dev.txt && python -m pytest -q`.

## Совместимость с v0.5, v0.4 и v0.3

1. Сделай резервную копию `data/velton.sqlite3`. Заменяй исходники, но **не удаляй `data/`**.
2. При старте приложение добавит таблицу игровых групп и поле `game_fixtures.group_no` в существующую SQLite. Уже начатые текущие сезоны остаются нетронутыми; новые правила групп применяются при генерации нового сезона.
3. Новые клубы доступны **в новых слотах**. Существующие пять независимых сохранений не переписываются автоматически.

Исходные версии исторического пакета и лицензии сохранены в `THIRD_PARTY_NOTICES.md`. Внешние клубные логотипы и фотографии не включены.
